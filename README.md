# Aplicación Web: Análisis de Anuncios de Venta de Coches en EE. UU.

## Descripción del Proyecto
Este proyecto consiste en el desarrollo y despliegue de una aplicación web interactiva de cuadro de mando (*dashboard*) construida con **Python**, **Streamlit** y **Plotly**. El objetivo principal es aplicar buenas prácticas de desarrollo de software, gestión de entornos virtuales, control de versiones con Git/GitHub y despliegue continuo en la nube utilizando **Render**.

La aplicación toma como base un conjunto de datos (`vehicles_us.csv`) que contiene anuncios de venta de vehículos en Estados Unidos.

## Funcionalidad de la Aplicación Web
La aplicación permite a los usuarios realizar un análisis exploratorio visual e interactivo de los datos mediante las siguientes funciones:

- **Histograma del Odómetro**: Permite visualizar la distribución del kilometraje (*odometer*) de los vehículos anunciados para identificar tendencias y concentraciones de uso.
- **Gráfico de Dispersión (Scatter Plot)**: Muestra la relación entre el precio (*price*) del vehículo y su kilometraje (*odometer*), facilitando el análisis de cómo afecta el uso al valor comercial de los autos.
- **Controles Interactivos**: Incorpora casillas de verificación (*checkboxes*) / botones que permiten al usuario activar o desactivar la visualización de cada gráfico dinámicamente en tiempo real.

## Herramientas y Tecnologías Utilizadas
- **Python 3.x**
- **Pandas**: Manipulación y análisis de datos.
- **Plotly Express / Graph Objects**: Creación de gráficos interactivos.
- **Streamlit**: Framework para el desarrollo de la interfaz de la aplicación web.
- **Render**: Plataforma en la nube para el hosting y despliegue de la aplicación.
